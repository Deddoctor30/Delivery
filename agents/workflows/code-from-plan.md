# Workflow: код по плану

Вход: слой (`backend` | `web` | `mobile`) и пункт плана.

1. Прочитай `agents/plans.md` → соответствующий `01-requirements/<слой>/PLAN.md`.
2. Прочитай `AGENTS.md` целевого слоя (версии, команды, конвенции). Не доверяй
   памяти по версиям фреймворков — сверяйся с AGENTS.md слоя.
3. Реализуй ТОЛЬКО указанный пункт, не выходя за его рамки.
4. Перед «готово»: прогон lint + typecheck командами из AGENTS.md слоя.
5. Отчитайся: файлы, что сделано, что осталось по пункту.
