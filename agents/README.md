# Мульти-агентный сетап

Проект ведут два агента. Этот хаб — единый источник; родные файлы каждого
агента (`.claude/`, `.clinerules/`) — тонкие указатели сюда.

## Агенты и зоны

| Задача                         | Claude Code | Cline (Qwen3) |
| ------------------------------ | :---------: | :-----------: |
| Код по планам (backend/web/mob)|      ✅     |      ✅       |
| Wire API (openapi → вызовы)    |      ✅     |      ✅       |
| Ревью / рефактор / тесты       |      ✅     |      ✅       |
| Чтение контекста и планов      |      ✅     |      ✅       |
| Pencil → код (MCP, субагенты)  |      ✅     |      ❌       |

## Где что
- Планы: [plans.md](plans.md) → `01-requirements/*/PLAN.md`
- Общие тела задач: [workflows/](workflows/)
- Контекст слоёв: `<слой>/AGENTS.md`

## Конвенция воркфлоу
`agents/workflows/<имя>.md` — что сделать и правила (tool-agnostic).
Claude вызывает через `.claude/commands/`, Cline — через `.clinerules/workflows/`.
Оба файла-обёртки только ссылаются на тело здесь — текст задачи не дублируется.
