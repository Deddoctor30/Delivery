---
description: Создать/обновить компонент(ы) дизайн-системы в shared/ui из Pencil
argument-hint: "[компонент или список через запятую]"
---

Запусти **одного** субагента `pen-ds-builder` с задачей: построить/обновить все компоненты дизайн-системы, перечисленные в `$ARGUMENTS`, в `src/shared/ui`, строго по `04-web-nextjs/docs/pencil-pipeline.md`.

`$ARGUMENTS` может содержать одно имя или **произвольное количество имён через запятую**. Если имён несколько — обработай их **за один прогон одним агентом**: каждый компонент — отдельный файл в `src/shared/ui`, но `src/shared/ui/index.ts` обнови **один раз в конце**, и один раз прогони `npm run format && npm run lint && npm run arch`. НЕ запускай несколько агентов параллельно (гонка по `index.ts`).

Если `$ARGUMENTS` пуст — сначала выполни разведку (как `/pencil-pull`), покажи, каких примитивов не хватает в `shared/ui`, и спроси, какой делать.

После работы агента: кратко отчитайся (что создано/изменено, результат format+lint+arch) и напомни про коммит в формате `feat(web): <components> design-system components`.
