# User flows

Ключевые пользовательские сценарии. Используются как для дизайна экранов, так и для проектирования API.

---

## 1. Поиск и выбор товара (гость или клиент)

```mermaid
flowchart TD
    A[Главная: каталог + поиск] --> B{Что делает пользователь?}
    B -->|Кликает на инпут поиска| C[Дропдаун: популярные товары]
    B -->|Вводит текст| D[Autocomplete: похожие товары]
    B -->|Идёт в категорию| E[Страница категории]
    C --> F[Карточка товара]
    D --> F
    E --> F
    F -->|Нажимает Купить| G{Авторизован?}
    G -->|Да| H[Товар в серверной корзине]
    G -->|Нет| I[Товар в localStorage корзине]
    H --> J[Бейдж корзины +1]
    I --> J
```

---

## 2. Регистрация / вход (единая модалка)

```mermaid
flowchart TD
    A[Клик на иконку профиля] --> B[Модалка: email + пароль]
    B --> C[POST /auth/login-or-register]
    C --> D{Email существует?}
    D -->|Да: проверка пароля| E{Пароль верный?}
    E -->|Да| F[JWT выдан, токены сохранены]
    E -->|Нет| G[Ошибка: неверный пароль]
    D -->|Нет: создаём аккаунт| H[User создан с минимумом данных]
    H --> F
    F --> I[Модалка закрывается]
    I --> J[ЛК доступен]
    J --> K{Профиль заполнен?}
    K -->|Нет| L[Подсказка: дополнить имя, фамилию,<br/>выбрать аватар из набора]
    K -->|Да| M[Готово]
```

## 3. Оформление заказа

```mermaid
flowchart TD
    A[Корзина: список товаров + общая сумма] --> B{Авторизован?}
    B -->|Нет| C[Открыть модалку входа/регистрации]
    C --> D[Корзина перенесена из localStorage в серверную]
    B -->|Да| E[Шаг: адрес доставки]
    D --> E
    E --> F[Карта: пользователь выбирает точку]
    F --> G[Геокодинг: координаты → адрес]
    G --> H[POST /delivery/estimate]
    H --> I[Срок доставки + стоимость доставки]
    I --> J[Калькуляция: товары + доставка = итого]
    J --> K[Кнопка Оплатить]
    K --> L[POST /orders<br/>имитация оплаты]
    L --> M[Заказ создан, статус: created]
    M --> N[Корзина очищена]
    N --> O[Редирект в ЛК → История заказов]
```

## 4. Отслеживание и отмена заказа

```mermaid
flowchart TD
    A[ЛК → История заказов] --> B[Список заказов со статусами]
    B --> C[Открытие конкретного заказа]
    C --> D[Таймлайн статусов из OrderStatusHistory]
    D --> E{Статус позволяет отмену?}
    E -->|created или processing| F[Кнопка Отменить]
    E -->|courier_picked_up и далее| G[Отмена недоступна]
    F --> H[POST /orders/:id/cancel]
    H --> I[Статус → cancelled, refunded: true]
    I --> J[Cron перестаёт двигать заказ]
```

## 5. Админка: пользователи и их заказы

```mermaid
flowchart TD
    A[Админ логинится] --> B{role === admin?}
    B -->|Нет| C[Доступ запрещён]
    B -->|Да| D[Раздел Админ-панель]
    D --> E[Список всех пользователей]
    E --> F[Клик на аккордеон пользователя]
    F --> G[Доп. инфо + список его заказов]
    G --> H{Действие?}
    H -->|Просмотр| I[Детали заказа]
    H -->|Отмена заказа| J{Статус позволяет?}
    J -->|Да| K[POST /admin/orders/:id/cancel]
    J -->|Нет| L[Кнопка отмены задизейблена]
    K --> M[Статус → cancelled, refunded: true]
```

## 6. Cookie-баннер

```mermaid
flowchart TD
    A[Первый визит на сайт] --> B[Баннер внизу: используем cookies]
    B --> C{Действие?}
    C -->|Принять| D[localStorage: cookies_accepted = true]
    C -->|Перейти на политику| E[Страница политики cookies]
    D --> F[Баннер скрыт навсегда]
    E --> B
```
