# Проект Delivery

Монорепо, слои в `01-*`…`05-*`. Общий контекст — [AGENTS.md](../AGENTS.md),
карта сетапа — [agents/README.md](../agents/README.md).

Перед работой в слое читай `AGENTS.md` этого слоя (версии/команды/конвенции).
Не доверяй памяти по версиям фреймворков — источник истины в AGENTS.md слоя.

## Работа в пределах окна контекста (~41k)

Окно маленькое — упираться будешь часто. Стратегия: сбрасывать рано, не «дотягивать».

- **Дроби задачи.** Один заход = один пункт плана / одна сущность. Не берись за
  «весь экран» или «всю фичу» за раз.
- **Начинай с чистого окна.** Закрыл логический кусок — заверши задачу (New Task),
  не тащи один диалог через всю фичу. Контекст дёшево восстановится из
  `AGENTS.md` + `.clinerules/` + `AGENTS.md` слоя.
- **Не читай лишнее.** Не открывай крупные файлы целиком и не `grep` по всему репо
  без нужды — ищи точечно по нужному FSD-слою/папке. `.clineignore` уже отсекает
  `node_modules/dist/.next/generated`.
- **При ~80% окна** — ужми контекст (Condense) или добей текущий пункт и начни
  заново. Не продолжай работу на переполненном окне.
- **Pencil/MCP не трогай** (см. `02-division-of-labor.md`) — эта зона тяжёлая по
  контексту и не влезет в 41k.
